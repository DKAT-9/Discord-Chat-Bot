# Discord Chat Bot 🤖
A Python-based chatbot built using discord.py that responds to user messages in real time.

## Features
- Asynchronous message handling (non-blocking)
- Custom knowledge base using JSON
- Secure token management with python-dotenv

## Tech Stack
Python · discord.py · asyncio · JSON · dotenv

## How to Run
1. Clone the repo  
   `git clone https://github.com/yourusername/discord-chat-bot`
2. Create a `.env` file  
   `DISCORD_TOKEN=your_token_here`
3. Run  
   `python3 main.py`
